Setting the password

Once you are signed in, change it from the change password page. That signs out every other admin session.

If you are locked out, run this on the server:

python seed.py --set-admin-password "your password here"

In Docker, set FIXITHUB_ADMIN_PASSWORD instead. Passwords are stored as bcrypt hashes and compared in constant time.
