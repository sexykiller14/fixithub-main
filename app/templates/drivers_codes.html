Device Manager error codes

A yellow exclamation mark always has a numbered code behind it. Open the device's Properties, read the General tab, and find the code below.

How to find the code

  1. 1. Press Windows key plus X and choose Device Manager.
  2. 2. Find the device with the yellow exclamation mark.
  3. 3. Double-click it and read the General tab.

Where not to get drivers

Never install drivers from sites that host every driver from every manufacturer, from pop-ups, or from "driver updater" software. These install unsigned drivers that Windows either refuses to load or that cause crashes. Use your PC vendor, the chip vendor, or the official Microsoft Update Catalog.
