Diagnostic tools

These are programs, not scripts. You cannot read their source, so each page tells you who publishes them, what version it is, and the SHA-256 checksum so you can confirm you received the exact file we uploaded.

Windows will warn you before you open one of these

Microsoft Defender and Windows SmartScreen flag programs downloaded from sites they do not recognise, because almost all malware arrives this way. A warning here is expected for any file on this page. It means Windows does not know this publisher, not that we know the file is unsafe. Read the checksum, and prefer the vendor's own download page when one is linked.

We host these as a convenience, and prefer vendors

Where a tool has an official download, that is almost always the better place to get it. The vendor signs their installer, so Windows recognises them, and you get their own update mechanism. Use a copy here when the vendor site is awkward to reach.
