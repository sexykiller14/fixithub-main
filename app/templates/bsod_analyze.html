Minidump analyzer

Windows records every blue screen. Upload the .dmp file and we will read the bugcheck code and its four parameters, then show you the matching fix guide.

Where to find your minidump

  1. 1. Open File Explorer and paste C:\Windows\Minidump into the address bar.
  2. 2. Sort by date and pick the most recent .dmp file.
  3. 3. Upload it below.

If that folder is empty, enable crash dumps: press Windows key plus R, type sysdm.cpl, go to Advanced > Startup and Recovery > Settings, and set Write debugging information to to Small memory dump.

Upload a dump file

Maximum {{ max_upload_mb }} MB. We accept the PMDMP, PAGEDU and PAGE signatures that Windows writes.

How your file is handled

  • • Parsed in memory only. It is never written to disk and never stored.
  • • Nothing inside the file is executed. A dump is data, not a program.
  • • The header signature is checked before any parser sees the file.
  • • Only metadata about the upload is recorded, so administrators can see abuse.
  • • Dump files can contain fragments of your filenames, so treat yours as private.

Prefer to do it yourself? Open the file in Microsoft's WinDbg and run !analyze -v.
