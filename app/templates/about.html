About FixIT Hub

{{ counts.articles }} guides and {{ counts.stop_codes }} blue screen stop codes, written for people who want to fix their own PC rather than open a support ticket.

What is here

  • Stop code lookup for {{ counts.stop_codes }} bugchecks, searchable by name or hex value, each with fixes ordered by likelihood.
  • Minidump analyzer that reads the bugcheck code and parameters out of a .dmp file in memory.
  • Seven guided wizards that ask a few questions and end with the fix that matches your answers.
  • Network tools for DNS, public IP, port, HTTP status and latency, with SSRF protection and rate limiting.
  • Driver guides for NVIDIA, AMD, Intel and Realtek, plus every Device Manager error code.
  • Diagnostic scripts shown in full, with every command explained in plain English.

What this site will not do

  • Run any command on your computer. Nothing here executes anything remotely.
  • Store your minidump file. Uploads are parsed in memory and discarded.
  • Link to third-party driver download sites. Every driver link is an official vendor page.
  • Ask for your email address, or track you across sites.
  • Reach private or internal network addresses with its tools.

A word about risk

Some fixes on this site involve editing the registry, changing BIOS settings, or opening your PC. Those steps carry real risk, and guides here mark them with a warning rather than burying them.

Never open a power supply. The capacitors inside hold a lethal charge even when it is unplugged from the wall.

Never change a storage controller mode between AHCI and RAID after installing Windows. The machine will not boot and you will need installation media to recover it.

Always back up before repairing a filesystem or resetting Windows. Repairs fail partway, and a failing drive can become unreadable.

Stop and ask a technician when a guide tells you to. Each stop code page ends with a note explaining which test result means you have reached that point.
