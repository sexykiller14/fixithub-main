How to treat a program from this site

  • •Nothing here is code signed, so Windows cannot confirm who published it. That is why SmartScreen warns you.
  • •Check the checksum before running. If it does not match the value on this page, delete the file.
  • •Where a vendor link is listed, prefer it. A signed installer from the vendor is safer than an unsigned copy.
  • •If a program asks you to disable antivirus or Defender, stop. Legitimate diagnostic tools never need that.
  • •Scan with Defender before running anything you did not get from the vendor.
